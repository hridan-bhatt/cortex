# VaultX

VaultX is a secure file sharing platform built using Spring Boot and PostgreSQL. The project focuses on implementing practical security concepts such as authentication, authorization, secure file sharing, audit logging, and integrity verification.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven

### Frontend (Planned)
- React
- Tailwind CSS

## Features

### Implemented
- User registration
- PostgreSQL integration
- User management foundation

### Planned
- JWT Authentication
- File upload & storage
- Secure share links
- Download limits
- Expiry-based sharing
- Audit logging
- Security dashboard
- Admin dashboard
- Email notifications
- File tags
- Integrity verification
- Global audit explorer
